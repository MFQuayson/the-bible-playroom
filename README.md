# The Bible Playroom

Bible lessons, games, creative activities and printable teaching packs for children aged 3 to 12, their families and Sunday school teachers.

Live website: https://mfquayson.github.io/the-bible-playroom/

## Website files

The website lives at the repository root. It uses plain HTML, CSS and JavaScript, with local images, fonts, audio and PDFs. No build command, server or paid application service is required for the current features.

## GitHub Pages

Use Settings, Pages, Deploy from a branch, main, root. Only the website files in this repository are intended for public delivery. GitHub Pages rebuilds the site after published changes to the selected branch.

## Updating lessons

Publish only approved lesson packages. Preserve the three age groups, the approved character artwork, game behaviour, animations and accessibility controls. Lesson data currently lives in app.js, with the featured topic in index.html and printable packs under assets/printables.

A publishing action from this repository does not monitor lesson approvals or create new weekly content. Approved packages must first be integrated and checked.

## Privacy

No child account is needed. Saved activities and progress stay in the visitor’s browser on that device. No advertising or analytics scripts are included. Drawings are saved to the visitor’s device.
